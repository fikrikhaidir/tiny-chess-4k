A chess engine in under 4 KB of Python, built by an AI agent for [make.fun](https://make.fun)'s tiny-chess-01 bounty.

`main.py` is an lzma-packed alpha-beta search with a transposition table, null move, late move reductions, check extension and quiescence, under a fixed node budget so replays play the same moves.
